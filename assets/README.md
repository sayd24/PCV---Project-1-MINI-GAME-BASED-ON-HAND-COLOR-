# Aset game

Letakkan gambar PNG transparan di folder ini:

- `rumput.png` untuk tekstur rumput seluruh lapangan.
- `bola.png` untuk bola.
- `lubang.png` untuk lubang.
- `tembok.png` untuk semua tembok.

Game otomatis menyesuaikan gambar lapangan ke ukuran jendela. Gambar yang tidak tersedia akan memakai latar hijau atau bentuk sederhana sebagai fallback.
